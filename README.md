# GSSEM SOLUTION 홈페이지 임시 원페이지 시안

주식회사 지셈솔루션(GSSEM SOLUTION CO., LTD.)의 정식 홈페이지 제작 전 임시 원페이지 시안입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 원페이지. 회사 소개, 라인업, 주요 제품, 장점, 기술·제조, 인증, 연혁, 글로벌·OEM, 그룹, 문의·오시는 길 |
| `ifu.html` | 전자 사용설명서(eIFU) 포털 |
| `catalog.html` | 자료실. 카탈로그 PDF 3종 |
| `privacy.html`, `terms.html` | 개인정보처리방침, 이용약관 자리 |
| `assets/img`, `assets/video`, `assets/docs` | 제품 사진, 히어로 영상, 카탈로그 PDF |

빌드 도구 없이 `index.html`을 브라우저로 열면 됩니다. 영어가 기본이고 헤더에서 한국어와 다크·라이트 테마를 전환합니다.

## 주의

- 시안 단계라 모든 페이지에 `noindex` 메타가 있습니다. 정식 오픈 시 제거합니다.
- Google 지도, Pretendard 글꼴, Material Symbols, 개념 사진 13장(Pexels 외부 링크)은 인터넷 연결이 필요합니다. 개념 사진은 오픈 전 자사 촬영본으로 교체하거나 내려받아 자체 호스팅합니다.
- 설계 문서(자료 인벤토리, 팩트시트, 섹션 설계, 추가 확보 자료 목록)는 이 저장소에 포함하지 않습니다.
